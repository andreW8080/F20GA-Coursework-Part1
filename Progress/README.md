### Project Overview
For Part 1 of the coursework, I have chosen to create a 3D lantern model using Blender and place it within a nighttime environment.

The aim is to create a scene where the lantern acts as the main source of light, providing a warm glow against a darker surrounding environment.

The final render will focus on showcasing the lantern while using lighting and shadows with the surrounding environment to create a clear atmosphere.

## 3. Development Progress

Version 1 – Initial Lantern Model

The initial model I created consisted of a square base, four supporting pillars, a tapered roof, a top collar and aa hanging loop.

At this stage I focused on establishing the overall shape and proportions of the lantern before introducing additional details, materials and lighting.

Version 2 – Improved Lantern Geometry

Following the initial model I made several improvements to the geometry to make the lantern appear more detailed and realistic.

The main improvements for this version included:

- Added bevels to the lantern's frame and pillars to make the edges look less sharp and give the model a bit more depth.
- Added extra detailing around the bottom of the lantern to improve its appearance.
- Created an additional frame underneath the roof to make the structure look more complete.
- Made the hanging loop smoother by increasing the number of segments used.

Overall these changes helped make the lantern look more detailed and realistic while keeping the same basic design as Version 1.

Version 3 – Materials and Lighting

Following the improvements made in Version 2, I focused on adding materials and lighting to make the lantern look more realistic.

The main improvements for this version included:

- Added a dark metallic material to the lantern's frame, pillars and roof to give it a more realistic appearance.
- Added transparent glass materials to the lantern panels so the inside of the lantern could be seen.
- Applied a material to the lightbulb to give it a glowing appearance.
- Added a warm point light inside the lantern to simulate the light produced by the bulb.
- Adjusted the lighting to improve the visibility of the lantern's details and materials.

Overall these changes helped improve the appearance of the lantern by introducing different materials and lighting effects. This also prepares the model for the next stage which is where I will be focusing on creating the surrounding scene and improving the final render.

Version 4 – Nighttime Environment and Scene Composition

Following the materials and lighting improvements made in Version 3, I focused on creating the surrounding environment for the lantern.

The main improvements for this version included:

- Added a stone platform underneath the lantern to give it a surface to sit on.
- Changed the background to a dark blue colour to create a nighttime atmosphere.
- Added an external area light with a cool blue colour to contrast with the warm lighting inside the lantern.
- Introduced additional shadows and lighting effects to improve the overall appearance of the scene.

Experimented with the scene composition to make the lantern the main focus of the render.

Overall these changes helped establish a nighttime setting for the lantern and made the render feel more like a complete scene. The next version will focus on adding more detail to the surrounding environment.

Version 5 – Improved Environment and Final Scene Development

Following the initial night time environment created in Version 4, I focused on adding more detail to the surroundings and improving the overall composition of the scene.

The main improvements for this version included:

- Added individual paving stones to create a more detailed ground surface.
- Added a stone wall behind the lantern to give the scene more depth.
- Added a wooden crate as an additional object within the environment.
- Adjusted the size and positioning of the surrounding objects to make sure the lantern remained the main focus.

Improved the lighting and render settings to produce a clearer final image.

Overall these changes helped make the nighttime environment more detailed and gave the lantern a more complete setting. The additional objects, materials and lighting also helped improve the overall appearance and atmosphere of the scene.
